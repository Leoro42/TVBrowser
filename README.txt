КАК ПОЛУЧИТЬ APK (без установки программ на компьютер)
1. Зарегистрируйтесь на github.com, создайте новый репозиторий (New repository).
2. Загрузите в него ВСЕ файлы и папки из этого архива
   (Add file -> Upload files; важно сохранить папки, включая скрытую .github).
3. Вкладка Actions -> дождитесь зелёной галочки (3-6 минут).
4. Откройте завершённую сборку -> внизу Artifacts -> TVBrowser-apk -> скачается zip с app-debug.apk.
5. Скопируйте app-debug.apk на флешку.

УСТАНОВКА НА ТВ
1. Установите из Google Play на ТВ файловый менеджер (X-plore или File Commander).
2. Разрешите ему установку из неизвестных источников
   (Настройки -> Настройки устройства -> Безопасность и ограничения).
3. Вставьте флешку, откройте app-debug.apk, нажмите Установить.
4. Приложение "ТВ Браузер" появится в списке приложений.
5. Установите Happ на ТВ и добавьте подписку - кнопка "Happ" на стартовой странице его откроет.
